| Element | Analyst View | Fan View |

| **Filters** | Upfront | Hidden by default |

## Psychology: Why This Works

### Old Approach (Analyst Tool)
```
User: "Here's data"
Fan: "Why should I care?"
User: "It's useful information"
Fan: "For what?"
User: [Silence]
```

### New Approach (Journalism Platform)
```
User: "Sinner is on FIRE - 7 wins in 10"
Fan: "Wow, really? Tell me more!"
User: "He crushes hard courts but struggles on clay"
Fan: "That's interesting! Show me the numbers"
User: [Detailed stats]
Fan: "Perfect, now I understand the full picture"
```

**Key insight:** Story creates curiosity. Curiosity drives engagement. Data confirms the story.
